# Diabetes mellitus · written questions (SAQ)

صفحة واحدة (ملف HTML واحد) فيها **90 سؤال Written SAQ** على محاضرة السكري، مقسومة على 10 أقسام.

## إزاي تفتحها
- على جهازك: نزّل `index.html` وافتحه بالدبل كليك (مفيش سيرفر ومفيش إنترنت مطلوب).
- على النت: فعّل **GitHub Pages** من Settings → Pages → Branch: main / root، وبعد دقيقة هتشتغل على:
  `https://<username>.github.io/<repo-name>/`

## المميزات
- كل سؤال: *Mention the two / three / four / five / six …* — طلب واحد، من 2 لـ6 نقاط، والنقاط 1–3 كلمات.
- زر 👁 الإجابة المثالية لكل سؤال، وزر 🤖 تصحيح بالـAI (Gemini، وGroq اختياري للسرعة).
- لوحة كتابة بالقلم (stylus) — القراءة إنجليزي فقط.
- بحث بالكلمات + فهرس + عدّاد الأسئلة الغلط.
- إجاباتك بتتخزن في المتصفح نفسه (localStorage) — مفيش أي رفع لسيرفر.
